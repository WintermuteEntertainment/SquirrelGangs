# SquirrelGangs

2D squirrel fighting game with acorns and stash bombs. Built in Unity.

## Demo

This repo contains a playable Windows demo build of SquirrelGangs.

### Running the Demo

1. Download or clone the repo
2. Run `SquirrelGangs.exe`

## Requirements

- Windows 10/11
- No installation needed — just run the exe

## Build Info

- Engine: Unity (Mono backend)
- Platform: Windows x86_64
- Large binary assets tracked via Git LFS
